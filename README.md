# FUTURE_DS_03

## 📌 Project Overview
This project was completed as part of the Data Science & Analytics Internship by Future Interns.

The objective of this task was to analyze online shopper behavior, conversion funnels, and customer engagement using Power BI dashboards.

---

## 📊 Tools & Technologies Used
- Power BI
- Excel
- Data Visualization
- Business Analytics

---

## 📁 Dataset
The dataset contains online shopper interaction data including visitor activity, engagement metrics, traffic sources, and conversion information.

---

## 📈 Key Insights
- Returning visitors showed significantly higher purchase intent.
- Traffic sources with lower bounce rates generated stronger conversions.
- Most users interacted with fewer than 50 product pages.
- High engagement did not always guarantee purchases.
- Overall conversion rate observed was approximately 15%.

---

## 📊 Dashboard Features
- Funnel Conversion Analysis
- Customer Behavior Analysis
- Traffic Source Conversion Analysis
- Visitor Segmentation
- Monthly Conversion Trends
- Engagement vs Purchase Intent Analysis
